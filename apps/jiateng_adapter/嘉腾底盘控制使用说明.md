# 嘉腾底盘控制使用说明

本文说明嘉腾底盘的位置、速度话题，以及 `jiateng_adapter` 测试脚本的
基本用法。下列命令会产生真实运动，执行前先确认现场环境。

## 1. 环境准备

```bash
cd ~/letools_opensource
source infrastructure/ros_packages/devel/setup.bash
```

检查话题是否有订阅者：

```bash
rostopic info /cmd_pose
rostopic info /cmd_pose_world
rostopic info /cmd_vel
```

## 2. 话题接口

| 功能 | 话题 | 类型 | 坐标系 |
|---|---|---|---|
| 相对位置 | `/cmd_pose` | `geometry_msgs/Twist` | 机器人本体坐标系 |
| 绝对位置 | `/cmd_pose_world` | `geometry_msgs/Twist` | 下位机世界坐标系 |
| 速度控制 | `/cmd_vel` | `geometry_msgs/Twist` | 机器人本体坐标系 |

字段单位：

```text
linear.x / linear.y：位置 m 或速度 m/s
angular.z：yaw 角 rad 或角速度 rad/s
```

### 2.1 相对位置

机器人向 x 正方向移动 `0.10m`：

```bash
rostopic pub -1 /cmd_pose geometry_msgs/Twist \
'{linear: {x: 0.10, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}'
```

位置控制的预计到达时间：

```bash
rostopic echo /lb_cmd_pose_reach_time
```

### 2.2 绝对位置

移动到下位机世界坐标 `x=0.50m`、`y=0.20m`、`yaw=0rad`：

```bash
rostopic pub -1 /cmd_pose_world geometry_msgs/Twist \
'{linear: {x: 0.50, y: 0.20, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}'
```

`/cmd_pose_world` 的坐标原点由下位机定义，不应直接视为 AMCL 的 `map`
坐标。需要使用 `map` 目标时，使用嘉腾 `/move_base/move_to_target` 接口。

### 2.3 速度控制

现场转发链：

```text
/cmd_vel → /nodelet_manager → /move_base/base_cmd_vel
         → /leju_node → 嘉腾底盘
```

开启外部 `/cmd_vel` 转发：

```bash
rosservice call /enable_vel_control "data: true"
```

以 `20Hz` 发布 `0.10m/s` 前进速度：

```bash
rostopic pub -r 20 /cmd_vel geometry_msgs/Twist \
'{linear: {x: 0.10, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}'
```

按 `Ctrl-C` 停止连续发布，并发送一次零速度：

```bash
rostopic pub -1 /cmd_vel geometry_msgs/Twist \
'{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}'
```

不再使用外部速度时关闭转发：

```bash
rosservice call /enable_vel_control "data: false"
```

`data=true` 不会禁用嘉腾 `/move_base`。不要同时使用外部 `/cmd_vel` 和
导航任务输出非零速度。

## 3. 嘉腾测试脚本

| 脚本 | 用途 |
|---|---|
| `test_base_move.py` | 嘉腾相对移动、旋转 |
| `test_move_to_target.py` | 嘉腾 map 绝对位置 |
| `test_enable_vel_control.py` | 外部 `/cmd_vel` 转发开关 |

每个脚本末尾都有 `suite.addTest(...)`。运行前只保留一个未注释用例，避免
一次执行多个运动。

相对移动：

```bash
python3 apps/jiateng_adapter/test_base_move.py
```

调用：

```python
hardware.base_move_relative_jiateng(...)
hardware.check_arrived_jiateng(...)
```

绝对位置：

```bash
python3 apps/jiateng_adapter/test_move_to_target.py
```

调用：

```python
hardware.base_move_to_target_jiateng(...)
hardware.check_arrived_jiateng(...)
```

外部速度通道：

```bash
python3 apps/jiateng_adapter/test_enable_vel_control.py
```

用例：

```text
test_01_get_current_state  读取状态
test_02_set_false          关闭外部速度转发
test_03_set_true           开启外部速度转发
```

## 4. 注意事项

- 直接话题控制没有嘉腾导航 `task_id` 和 `check_arrived`。
- 需要导航避障、任务状态和到达查询时，优先使用嘉腾测试脚本对应的
  `/move_base` 服务。
- `/enable_vel_control_state` 可能只在状态改变时发布。
- 不要用 pytest 执行整个测试文件，否则会发现并执行全部 `test_*` 方法。
