# 02 平台适配说明

> 新增平台时按 [`05-03-扩展-adapters-层`](../05-进阶开发指南/03-扩展-adapters-层.md) 的「新增底盘后端」步骤落地。

同一套 LeTools 上层代码要跑在不同底盘上，差异**只允许**落在 `adapters` 层的品牌子目录里。

## 一、两个底盘后端（嘉腾 / 玖物）

> 术语：本文用「**玖物**」指代 JiBot/Jarvis 系底盘，代码中一律为 `jibot`。**嘉腾**对应代码中的 `jiateng`。

| | 嘉腾 | 玖物（JiBot / Jarvis） |
|---|---|---|
| 代码目录 | `adapters/hardware/leju_wheeled/mixins/jiateng/chassis_mixin.py` | `adapters/hardware/leju_wheeled/mixins/jibot/chassis_mixin.py` |
| 类名 | `JiatengChassisMixin` | `JibotChassisMixin` |
| 方法后缀 | `_jiateng` | `_jibot` |
| 相对移动 | `/move_base/base_move` | `/move_base/base_move` |
| 绝对目标 | `/move_base/move_to_target` | `/move_base/move_to_target` |
| 到达检查 | `/move_base/check_arrived` | `/move_base/check_arrived` |
| 速度控制权限 | `_jiateng` 版（`SetBool` 路径） | `/enable_vel_control`（`std_srvs/SetBool`） |
| 状态读取 | `_read_vel_control_state_jiateng` | `/enable_vel_control_state`（`std_msgs/Bool`） |

两者都通过 **ROS 服务**调用底盘，都依赖 `leju_mobile_base_msgs` 消息包
（`base_move` / `move_to_target` / `check_arrived`），服务等待超时均硬编码为 `SERVICE_WAIT_TIMEOUT = 5.0`。

## 二、适配机制：路由而非分支

上层**不感知**底盘品牌。调用链固定为：

```
上层 → NavigationChassisMixin.move_chassis_relative(...)   # 无厂商名的标准接口
     → 按 config/app_config.yaml 的 navigation_chassis_backend 路由
     → JiatengChassisMixin.base_move_relative_jiateng(...)
        或 JibotChassisMixin.base_move_relative_jibot(...)
```

- 路由表定义在 `adapters/hardware/leju_wheeled/mixins/navigation_chassis_mixin.py`
  的 `_NAVIGATION_METHODS`，每个后端注册五个能力键：
  `relative` / `target` / `arrived` / `set_external` / `get_external`。
- 选择项：`config/app_config.yaml` 的 `navigation_chassis_backend`（当前值 `jibot`）。
- **新增一个底盘后端 = 新增一个品牌子目录 + 在路由表登记这五个能力键**，
  上层代码零改动。扩展步骤另见 `05-03-扩展-adapters-层`。

## 三、对应的验证脚本

- 嘉腾：`apps/jiateng_adapter/`（`test_base_move.py` / `test_move_to_target.py` /
  `test_enable_vel_control.py`，复用 `_scaffold.py`）
- 玖物：`apps/jibot_adapter/`（适配器层）

## 四、其他平台差异（素材索引）

- 机器人型号与底盘对应关系（如 `"61": {"desc": "玖物底盘轮臂"}`）：
  `infrastructure/ros_packages/src/kuavo_common/python/robot_version.py`
- 机型相关配置出口：`config/app_config.yaml`（`robot_type`、
  `navigation_chassis_backend`）、`config/robot_config.yaml`
- 适配器创建入口：`adapters/hardware/factory.py`（`robot_type` →
  `leju_wheeled` / `leju_bipedal` / `mock`）
