# 01 参考资料

本篇汇总项目相关的官方与第三方参考资料。

标注口径：**官方** = 项目/厂商自己维护；**上游** = 依赖来源；**社区** = 第三方维护。

## 一、乐聚官方

| 名称 | 链接 | 权威度 |
|---|---|---|
| 乐聚机器人官网 | https://www.lejurobot.com/zh | 官方 |
| 乐聚官方文档站 | 由售后/技术支持分发，见根 `README.md` 的「支持与反馈」段 | 官方 |

## 二、上游与开源仓库

| 名称 | 链接 | 说明 |
|---|---|---|
| LeTools 开源仓（GitCode） | https://gitcode.com/OpenLET/letools_opensource | 主投放端；Issues 入口在此 |
| LeTools 开源仓（GitHub） | https://github.com/LejuRobotics/letools_opensource | `master` 在此映射为 `main` |
| kuavo-ros-opensource | https://gitcode.com/OpenLET/kuavo-ros-opensource.git（分支 `master`） | SDK 子模块来源（`drivers/leju/kuavo_humanoid_sdk`） |
| LeTools-Learning | https://github.com/LejuRobotics/LeTools-Learning（分支 `main`） | 学习/训练/部署工具链，本仓 submodule |

> SDK 子模块的来源见仓库根目录的 `.gitmodules`。

## 三、框架与运行时

| 名称 | 链接 | 说明 |
|---|---|---|
| ROS Noetic | http://wiki.ros.org/noetic | ROS 1 最后一版，Ubuntu 20.04 |
| PyTrees | https://py-trees.readthedocs.io/ | 行为树运行时；兼容 0.7.x / 2.x，见 `02-环境安装/02-依赖版本清单` |
| colorlog | https://pypi.org/project/colorlog/ | 日志着色，`core/common/logger.py` 使用 |
| Python | https://www.python.org/ | 3.8+ |

## 四、外设与第三方 SDK

| 名称 | 链接 | 用途 |
|---|---|---|
| AprilTag（C 库） | https://github.com/AprilRobotics/apriltag | 视觉标签定位 |
