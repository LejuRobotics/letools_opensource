## 一、你现在会了什么

走完 [04-简单案例运行](../04-简单案例运行/) 这一章，你应该能：

- 用 `run_behavior_tree_json.py --scenario … --dry-run --tick-once` 离线校验一棵树；
- 在仿真或真机上跑通由简到难的示教场景（头部 → 双臂 → 躯干 → 底盘）、搬箱场景和模仿学习上料场景；
- 读懂 `py_tree.json` / `py_tree_child.json` / `board.json` / `hardware_config.json` 四类文件；
- 分清「JSON 编排 → 节点 → 技能 → 适配器 → SDK」五层各管什么；
- 改一个参数并预判现象，报错时能定位到「环境 / 路径 / JSON / 节点 / 硬件」哪一类。

## 三、几个具体的「接着做」

1. **给现有场景加一个动作** → 先复制一个示教场景目录（如 `instructional_case_02`），按 [08](08-头手躯干并行-instructional_case_03.md) 第三节组合 planner、修改 `board.json`，
   再照 [05-进阶开发指南/05](../05-进阶开发指南/05-扩展-orchestration-层.md) 的步骤做。
2. **把新硬件接进来** → [05-进阶开发指南/03](../05-进阶开发指南/03-扩展-adapters-层.md)，
   并对照 [`03-接口详细文档/02`](../03-接口详细文档/03-adapters-硬件适配层.md) 的适配器契约。
3. **选择控制路径** → [`03-接口详细文档/09-控制路径与选型.md`](../03-接口详细文档/09-控制路径与选型.md)：
   「标准接口 / SDK 直调 / TimedCmd」三条路径的适用场景与取舍。
4. **报错排障** → [06-常见问题FAQ/04-行为树与场景运行](../06-常见问题FAQ/04-行为树与场景运行.md)（排障清单）、
   [05-常见错误](05-常见错误.md)（教学性排错顺序）。
