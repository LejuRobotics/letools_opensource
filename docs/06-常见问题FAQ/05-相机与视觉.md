## 1. 问题：相机初始化失败

**原因**：相机驱动库（如 `libOrbbecSDK.so.1.10`）损坏或链接缺失；设备未被识别；Topic 命名与预期不符。

**判断命令**

```bash
lsusb
ldconfig -p | grep -E 'Orbbec|realsense'
find /usr /usr/local -name 'libOrbbecSDK.so*' 2>/dev/null
rostopic list | grep -E 'camera|image|depth'
```

**解决方案**：Orbbec 常见问题是 `libOrbbecSDK.so.1.10` 损坏或链接缺失。应从正式安装包或同版本仓库恢复。

**成功标准**：只有 RGB、深度 Topic 持续有数据才算初始化成功。

**日志位置**：`~/.ros/log/latest/`，先看相机驱动节点的第一条 `ERROR`。

## 2. 问题：能看到 AprilTag 但检测不到

**原因**：tag 家族、ID、实际边长与配置不符；图像 Topic 或 `camera_info` 不匹配；apriltag 节点未连到正确话题。

**判断命令**

```bash
cat config/apriltag_config.yaml
rostopic hz /相机图像topic
rostopic echo -n 1 /相机内参topic
rosnode info /apriltag节点
```

若第一条报文件不存在，先 `cp config/apriltag_config.yaml.template config/apriltag_config.yaml`，再按需修改标签家族、ID 与边长。该文件不进 git，实际配置以本地副本为准。

**解决方案**：核对 tag 家族、ID、实际边长、图像 Topic 和 `camera_info`。仓库示例可能按 10 cm 标签配置，实际尺寸不同时必须修改配置。

**成功标准**：`rosnode info` 显示 apriltag 节点已订阅图像与内参话题，且在视野内能看到检测结果。

## 3. 问题：TF republisher 找不到包或 executable

**原因**：`kuavo_tf2_web_republisher` 被 skip，或当前终端未加载该工作空间。

**判断命令**

```bash
cd ~/letools_opensource/infrastructure/ros_packages
source /opt/ros/noetic/setup.bash
source devel/setup.bash
rospack find kuavo_tf2_web_republisher
./start_tf_republisher.sh
```

**解决方案**：若 `rospack find` 失败，检查该包是否被 skip，以及当前终端是否加载了这个工作空间。

**成功标准**：`rospack find` 返回包路径，`start_tf_republisher.sh` 能正常启动。

> 该包在 skip 视觉依赖时**不要**一并跳过，见 [01 安装与环境](01-安装与环境.md)。
