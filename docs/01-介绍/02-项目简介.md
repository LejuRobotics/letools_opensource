# 02 项目简介

[返回文档首页](../README.md) · [01-介绍](../01-介绍/) · [02-环境安装](../02-环境安装/)

> 本篇说明 LeTools 是什么、能做什么、不做什么，帮助你判断手上的需求是否适合用 LeTools 实现。

**LeTools 是乐聚 Kuavo 机器人上位机侧的 Python 技能工具链**：把机器人的底层控制能力封装成
**原子技能（Skill）**，再用 **行为树（PyTrees）** 把这些技能编排成可配置、可复用的任务流程。

## LeTools 是什么

执行一个场景时，控制命令的大致流向如下（模块依赖规则与详细调用流程见 [`04-系统架构与分层.md`](04-系统架构与分层.md)）：

```text
apps            示例和测试（跑得起来的最小脚本）
  ↓
orchestration   行为树编排（JSON 描述流程 + 薄节点）
  ↓
skills          原子技能（一个技能 = 一段明确动作）
  ↓
adapters        硬件适配（含 SDK 管理服务，实现 IHardware）
  ↓
drivers / infrastructure    SDK 与 ROS（底层支撑，应用不直接调用）
  ↓
MuJoCo 仿真 或 真机
```

LeTools 负责任务层面的决策：先做什么、后做什么、每一步的目标值是多少，并把这些指令转换为运控可以接收的 ROS 消息或 SDK 调用。
关节级的实时控制由下层运控（`kuavo-ros-opensource`）完成。

## 能做什么

| 能力 | 落地形态 |
|---|---|
| **原子动作** | 头部转向、手臂关节/末端轨迹、底盘速度/位置、腿部关节、躯干位姿、末端夹爪/灵巧手开合 |
| **任务编排** | 用 `py_tree.json` / `py_tree_child.json` / `board.json` 描述阶段顺序、并行、分支，不改代码即可调整流程 |
| **视觉对接** | AprilTag / 二维码 / 目标检测结果的读取；Tag 位姿经坐标链换算为抓取目标 |
| **三级运行环境** | 干跑（`--dry-run`，无 ROS 无硬件）→ MuJoCo 仿真 → 真机 |
| **工业场景** | 搬箱、拆垛、小件上料等已落地场景 |
| **可扩展** | 分层的扩展点：新硬件进 `adapters`、新动作进 `skills`、新节点进 `orchestration`、新场景进 `scenarios` |

## 不做什么

明确边界，避免把不该改的东西改坏：

| 不负责 | 归谁 |
|---|---|
| 底层运动控制算法（MPC / WBC） | 运控仓库 `kuavo-ros-opensource`（C++ 控制器） |
| 关节级运动学求解与实时控制环 | 运控仓库 |
| 硬件驱动、电机固件 | 运控仓库 / 驱动 |
| 视觉算法本身的实现（检测模型训练） | 视觉包与模型侧 |
| 认知决策/大模型推理 | 需接入时由场景侧自行对接（`inference_*` 节点属场景实现） |

> LeTools 不提供新的底层控制能力，而是把已有能力组织成可配置、可复用、可验证的任务。

## 与周边仓库的关系

| 仓库 | 角色 | 与本项目的关系 |
|---|---|---|
| `kuavo-ros-opensource` | 运控：MPC/WBC 控制器、URDF、MuJoCo 仿真、`kuavo_msgs` | LeTools 的下层依赖；SDK 也来自这里（submodule） |
| `LeTools`（本项目） | 上位机技能工具链与行为树 | — |
| `letools_opensource` | LeTools 的开源发布形态 | 职责与 LeTools 相同，仅发布口径不同 |
| `LeTools-Learning` | rosbag 转换 / 模型训练 / VLA 推理部署 | submodule，独立工具链，不参与行为树运行时 |

## 典型适用场景

- **工业取放 / 搬箱**：相机识别箱体 Tag → 底盘走到位 → 手臂抓取 → 搬运 → 放下。参考场景 `refactored_sdk_single_tag_pick_v0`、`grasp_mtbf`。
- **单项能力验收**：只想验证「头部能不能转 30 度」「手臂能不能走一条轨迹」时，用 `apps/` 下的示例脚本。
- **流程调试**：不改代码，只想调整「先导航还是先抓」，改场景 JSON 即可。
- **仿真先行**：真机成本高，先在 MuJoCo 里把逻辑跑通，再迁真机。

## 常用目录速查

| 目录 | 用途 | 新手何时需要查看 |
|---|---|---|
| `apps/` | 可运行示例和测试入口 | 想运行单项功能时 |
| `orchestration/` | 行为树节点、场景和加载器 | 想运行或修改业务场景时 |
| `skills/` | 原子技能 | 想复用或开发动作能力时 |
| `adapters/` | 将统一接口连接到具体硬件（含 SDK 管理服务） | 想新增硬件能力时 |
| `core/` | 接口契约、数据模型、通用工具（不依赖项目内其他层） | 想知道「标准调用长什么样」时 |
| `drivers/` | 底层驱动（SDK submodule） | **一般不用看** |
| `infrastructure/` | catkin 工作空间（消息包、视觉、TF 转发） | 需要编译 ROS 包时 |
| `config/` | 应用级 / 机器人 / 相机 / 日志配置 | 改运行参数时 |
| `scripts/` | 安装与运行脚本（含 SDK 版本锁） | 装环境、装 SDK 时 |
