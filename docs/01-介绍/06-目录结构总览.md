## 一、目录树

```text
LeTools
├── core/                        # 契约层：接口、数据模型、通用工具（不依赖项目内其他层）
│   ├── interfaces/              #   IHardware / ISkill / ICamera / IPerception
│   ├── domain/                  #   Result / Pose6D / JointState / Trajectory / SkillParams / enums
│   └── common/                  #   logger / config_loader / transform / ros_environment / exceptions
├── drivers/                     # 底层驱动层（SDK 由下游用户自行安装）
│   └── leju/                    #   乐聚相关驱动入口
├── adapters/                    # 硬件适配层（★ 开发者主要调用入口；开源产物中以 .pyc 分发）
│   ├── hardware/
│   │   ├── factory.py           #   HardwareFactory：按 robot_type 创建适配器
│   │   ├── leju_wheeled/        #   轮臂主适配器（Mixin 组合）
│   │   │   ├── mixins/          #     各能力 Mixin（底盘/躯干/手臂/力控/模式/末端/反馈/TimedCmd/SDK 直调/导航路由）
│   │   │   ├── services/        #     sdk_manager / state_manager
│   │   │   ├── source_sdk_compat/  # 跨 SDK 版本兼容层
│   │   │   └── tests/
│   │   └── leju_bipedal/        #   足式适配器
│   ├── vacuum_control/          #   真空吸盘控制适配器
│   ├── vacuum_485/              #   485 真空控制适配器
│   ├── upper_body_api.md        #   上半身 API 参考
│   ├── camera_chassis_api.md    #   相机与底盘 API 参考
│   └── README.md
├── skills/                      # 原子技能层（一个技能 = 一段明确动作）
│   ├── base/skill_base.py       #   SkillBase：超时 / 日志 / 异常的统一实现
│   └── atomic/
│       ├── refactored_sdk/      #   当前推荐的新 SDK 技能（一文件一技能）
│       ├── manipulation/        #   旧版操作技能
│       ├── motion/              #   旧版运动技能
│       ├── perception/          #   感知技能
│       └── grasp_skill.py       #   旧版抓取技能
├── orchestration/               # 行为树编排层
│   ├── main.py                  #   主入口：--dry-run / --tick-once
│   ├── engine/                  #   JSON → PyTrees 工厂、控制器、py_trees 兼容
│   ├── nodes/                   #   行为树节点（一个节点调用一个 Skill）
│   ├── scenarios/               #   场景 JSON（py_tree / py_tree_child / board / hardware_config）
│   ├── tasks/                   #   任务级 YAML 配置
│   ├── services/                #   黑板服务
│   ├── config/                  #   行为树配置（boards / skills / trees）
│   ├── parser/                  #   任务解析器
│   ├── shared_hardware.py       #   全局 IHardware 单例
│   ├── studio_tree.py           #   行为树服务 / Studio 侧入口
│   ├── utils/                   #   含 manifest_decorators.py（@define_manifest）
│   └── web_ui/
├── apps/                        # 示例与验证入口
│   ├── test_kuavo_5w_adapter/   #   适配器层硬件测试（01_base_control … 08_end_effector）
│   ├── test_kuavo_5w_sdk_adapter/    # SDK 接口验收
│   ├── test_kuavo_5w_skills/    #   技能层测试
│   ├── test_kuavo_5w_orchestration/  # 编排层节点测试
│   ├── test_camera_adapter/     #   相机适配器测试
│   ├── test_upper_init/         #   JSON 行为树启动器
│   ├── test_demo/               #   综合演示
│   ├── jiateng_adapter/         #   嘉腾底盘适配测试
│   └── jibot_adapter/           #   玖物（JiBot）底盘适配测试
├── infrastructure/              # ROS 基础设施
│   └── ros_packages/            #   catkin 工作空间：消息包 / 视觉 / 相机驱动 / TF 转发
├── config/                      # 配置文件
│   ├── app_config.yaml          #   应用级配置（robot_type / backend）
│   ├── robot_config.yaml        #   机器人参数
│   ├── camera_config.yaml.template   #   相机配置模板
│   ├── apriltag_config.yaml.template #   AprilTag 检测参数与 Tag 尺寸 / ID
│   ├── log_config.yaml          #   日志配置
│   ├── apriltag_continuous.launch
│   └── camera_orbbec.launch
├── scripts/                     # 安装与运行脚本
│   ├── install_sdk.sh           #   一键安装 SDK
│   ├── remove_local_sdk.sh      #   卸载本地 SDK
│   ├── run_arm_trajectory.sh / run_camera_demo.sh / run_smt_tray.sh
│   ├── setup_letools_learning.sh
│   └── kuavo_humanoid_sdk_tools/     # SDK 配置与版本锁（sdk_version.env）
├── tests/                       # 仓库级测试
├── third_party/                 # 第三方资源
├── docs/                        # 文档（本目录：01–08 章 + README + assets）
├── requirements.txt             # Python 运行时依赖（colorlog、py_trees）
└── README.md
```

`config/` 下的 `camera_config.yaml` 与 `apriltag_config.yaml` 由同名 `.template` 复制后按现场修改，本地文件不入库。

## 二、各顶层目录职责

| 目录 | 职责 | 新手何时需要查看 |
|---|---|---|
| `core/` | 定义契约与数据模型，不依赖项目内其他层 | 想知道「标准调用长什么样」时 |
| `drivers/` | 与 SDK / 硬件通信的底层封装 | **一般不用看**（应用代码不直接调用） |
| `adapters/` | 把具体硬件实现成 `IHardware`，**开发者主要调用入口** | 想调硬件、加硬件能力时 |
| `skills/` | 原子技能，一个技能一段明确动作 | 想复用或开发动作能力时 |
| `orchestration/` | 行为树节点、场景 JSON 与加载器 | 想运行或修改业务场景时 |
| `apps/` | 跑得起来的最小示例与测试 | 想跑单项功能验证时 |
| `infrastructure/` | catkin 工作空间（消息包、视觉、相机驱动、TF 转发） | 需要编译 ROS 包时 |
| `config/` | 应用 / 机器人 / 相机 / 日志配置 | 改运行参数时 |
| `scripts/` | 安装与运行脚本（含 SDK 版本锁） | 装环境、装 SDK 时 |
| `tests/` | 仓库级测试 | 想跑全仓测试时 |
| `third_party/` | 第三方资源 | 一般不用看 |
| `docs/` | 文档 | **就是本目录** |

各模块的详细说明另见根 `README.md` 的「项目结构」段，以及
[`02-项目简介.md`](02-项目简介.md) 的「常用目录速查」。

## 三、需要单独获取或以编译形式提供的部分

| 部分 | 说明 |
|---|---|
| **`adapters/` 的源码** | 以 `.pyc` 字节码分发（位于对应模块目录），调用方式不受影响，见 [`05-开发者调用路径.md`](05-开发者调用路径.md) 第四节 |
| **`drivers/leju/kuavo_humanoid_sdk`** | SDK 子模块，不随包提供，运行 `scripts/install_sdk.sh` 按锁定版本安装 |
| **`LeTools-Learning`** | 独立仓库（模型训练 / VLA 推理部署工具链），不属于行为树运行时，需要时单独获取 |
