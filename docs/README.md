# LeTools 文档

LeTools 是乐聚夸父（Kuavo）机器人上位机侧的 Python 技能工具链：把机器人能力按 `core`、`drivers`、`adapters`、`skills`、`orchestration`、`apps` 分层组织，用行为树把原子技能编排成可运行的场景任务。本页是文档入口：先按下面的路线选篇目，再按需查完整目录，不必从 `01-介绍` 开始顺序读完所有章节。

---

## 选一条路线开始

### 路线 A：快速开始（4 步，跑通第一个 dry-run）

适合第一次接触 LeTools、想先确认环境可用并看懂一个现成场景的读者。

| 步 | 目标 | 读什么 | 完成标志 |
|---|---|---|---|
| 1 | 认识 LeTools | [`01-介绍/02-项目简介.md`](./01-介绍/02-项目简介.md) | 能说出 LeTools 的输入（场景 JSON）、输出（机器人动作）和三级运行环境 |
| 2 | 准备环境 | [`02-环境安装/01-系统要求.md`](./02-环境安装/01-系统要求.md) → [`02-环境安装/03-安装步骤.md`](./02-环境安装/03-安装步骤.md) 第三节 | `bash scripts/check_environment.sh` 无 `E` 开头的阻断项 |
| 3 | 运行第一个 dry-run | [`04-简单案例运行/01-最小可运行示例.md`](./04-简单案例运行/01-最小可运行示例.md) | 输出 `tick 后根状态: Status.SUCCESS` |
| 4 | 理解示例并继续 | [`04-简单案例运行/03-行为树最小示例.md`](./04-简单案例运行/03-行为树最小示例.md)，再按下表选方向 | 能读懂 `py_tree.json` / `board.json` 的结构 |

第 4 步之后按需求选择：

| 想做什么 | 去哪里 |
|---|---|
| 在 MuJoCo 或真机上跑现成场景 | [`02-环境安装/03-安装步骤.md`](./02-环境安装/03-安装步骤.md) 第一、二节 → [`04-简单案例运行/`](./04-简单案例运行/) 的 06–11 篇（由简到难） |
| 查某个节点或技能怎么调用 | [`03-接口详细文档/11-节点清单.md`](./03-接口详细文档/11-节点清单.md)、[原子技能库](./03-接口详细文档/原子技能库/README.md) |
| 写新技能、新节点或新场景 | 路线 B |
| 遇到报错 | [`04-简单案例运行/05-常见错误.md`](./04-简单案例运行/05-常见错误.md)、[`06-常见问题FAQ/`](./06-常见问题FAQ/) |

**背景知识按需补充**：[`01-介绍/01-机器人基础通识.md`](./01-介绍/01-机器人基础通识.md) 介绍坐标与 TF、SLAM 与导航、ROS、仿真与真机、SDK、行为树。
dry-run 不需要这些知识；运行示教案例（06–09）前建议读 1.6「SDK 与 LeTools 分层」和 1.7「行为树入门」，运行搬箱和模仿学习案例（10、11）前再读 1.2「坐标系与 TF」和 1.3「SLAM 与导航」，上仿真或真机前读 1.4「ROS 是什么」和 1.5「仿真与真机」。
`03-接口详细文档` 是查阅手册，路线 A 不需要通读，改代码时再查。

## 完整文档地图

能力资料分两类：[原子技能库](./03-接口详细文档/原子技能库/README.md)按能力域索引代码中已有的技能；[案例库](./04-简单案例运行/案例库/README.md)索引已有教程覆盖的公开场景。代码中存在的技能或案例不等于已在所有硬件和场景上验证，查具体调用时请交叉核对技能源码、节点清单和对应案例。

| 章 | 定位 | 阅读建议 |
|---|---|---|
| [01 介绍](./01-介绍/) | 机器人基础通识、项目简介与核心特性、系统架构与分层、开发者调用路径 | **必修** `02`；`04` 为分层规则的权威说明 |
| [02 环境安装](./02-环境安装/) | 系统要求、依赖版本清单、安装步骤、环境验证、升级与卸载 | **必修**（`03-安装步骤` 为核心） |
| [03 接口详细文档](./03-接口详细文档/) | `core`/`adapters`/`skills`/`orchestration`/`apps`/`drivers`/工具层接口逐节说明书 | **选读**（路线 A 可跳过，路线 B 必修） |
| [04 简单案例运行](./04-简单案例运行/) | 由简到难的运行示例与场景逐层精讲 | **必修**（至少 `01`） |
| [05 进阶开发指南](./05-进阶开发指南/) | 逐层扩展方法、测试与调试 | **选读**（路线 B 必修） |
| [06 常见问题FAQ](./06-常见问题FAQ/) | 按问题域分篇的「问题 — 原因 — 解决方案」 | **选读**（随用随查） |
| [07 补充内容](./07-补充内容/) | 参考资料、平台适配说明 | **选读**（查词用 [`07-术语表`](./01-介绍/07-术语表.md)） |
| [08 贡献指南](./08-贡献指南/README.md) | 从切分支到合并的贡献流程、提交与合并请求规范、测试自检、文档写作、版本与兼容性 | **选读**（打算把改动合回仓库时必修） |
