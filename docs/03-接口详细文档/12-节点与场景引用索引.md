# 12 节点与场景引用索引

[返回文档首页](../README.md) · [节点功能与参数详表](./11-节点清单.md) · [行为树编排](./05-orchestration-行为树编排.md)

本文根据当前本地分支的节点 Python 类和场景树 JSON 静态整理。引用表示配置中出现，不代表运行时必经、测试通过或稳定公共 API。

## 一、分类口径

- 跨场景复用：同一个节点类名出现在至少两个不同场景目录的树 JSON 中。
- 单场景：只出现在一个场景目录；它的实现仍可能具有通用性。
- 未直接引用：源码中有该类，但本次扫描的树 JSON 未写出；可能由 Python 动态创建或其他入口调用。
- Sequence、Selector、Parallel 为控制节点；以 .json 结尾的是子树引用。子树模板被定义，不等于主树会运行它。
- board 类 JSON 提供黑板参数，hardware_config 类 JSON 提供硬件选择；它们本身不调用节点。

扫描范围：23 个场景目录、72 份树 JSON、114 个非控制节点名；其中 32 个跨场景复用、82 个单场景。
