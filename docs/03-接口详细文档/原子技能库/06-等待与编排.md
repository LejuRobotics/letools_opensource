## `wait_for_enter`

**用途**：等待人工按 Enter **源码**：`skills/atomic/refactored_sdk/wait_for_enter.py`。

**主要参数**：`message`；另有通用 `timeout`。全部字段和默认值以 `WaitForEnterParams` 为准。

**调用片段**：

```python
from skills.atomic.refactored_sdk.wait_for_enter import WaitForEnterParams, WaitForEnterSkill
params = WaitForEnterParams(message='确认后继续')
skill = WaitForEnterSkill()
result = run_skill(skill, params)  # run_skill 定义在本库 README
print(result.success, result.message)
```

**运行条件**：无需硬件适配器；仍需提供技能所需的实际输入。

**结果判定**：初始化与每次执行均检查 Result.success；只有 is_finished() 为真才算完成。失败时保留 message 并定位上游输入或适配器。本片段为源码核对示例，仿真/真机验证待逐项记录。
