## 头部单步：`HeadControlSkill`

源码：`skills/atomic/manipulation/head_control/skill.py`、`params.py`。它需要已经初始化的 `IHardware`，`yaw_deg` / `pitch_deg` 是角度。先按照[主手册的硬件创建示例](../04-skills-原子技能.md#直接构造运行一个技能)创建、初始化 `hw`，并核对现场可执行角度；再使用下列调用片段，最后执行 `hw.shutdown()`。

```python
from skills.atomic.manipulation.head_control.params import HeadControlParams
from skills.atomic.manipulation.head_control.skill import HeadControlSkill

skill = HeadControlSkill(hw)
params = HeadControlParams(yaw_deg=0.0, pitch_deg=0.0)
result = run_skill(skill, params)  # run_skill 见原子技能库 README
print(result.success, result.message)
```

## 底盘短动：`ChassisVelocitySkill`

源码：`skills/atomic/motion/chassis_velocity/skill.py`、`params.py`。`initialize()` 即可能下发底盘速度；**不能用它测试纯导入或无设备环境**。在仿真/真机控制器与安全边界确认后，使用[通用调用循环](README.md#调用与验证口径)检查 `Result` 和完成状态，结束时确保发送零速并关闭适配器。输入字段、默认值和坐标系以 `ChassisVelocityParams` 源码为准。

这些片段仅完成源码级核对，未在本轮文档整理中运行。其余旧版技能还缺逐项实测记录，不标为“已按文档复现”；新项目优先从[主力原子技能索引](README.md)选型。
