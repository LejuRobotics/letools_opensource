## `inference_control_skill`

**用途**：VLA 推理控制 **源码**：`skills/atomic/refactored_sdk/inference_control_skill.py`。

**主要参数**：`inference_config_path`, `policy_type`, `pretrained_path`, `task_prompt`, `max_episode_steps`, `device`；另有通用 `timeout`。全部字段和默认值以 `InferenceControlParams` 为准。

**调用片段**：

```python
from skills.atomic.refactored_sdk.inference_control_skill import InferenceControlParams, InferenceControlSkill
params = InferenceControlParams()
skill = InferenceControlSkill(hw)
result = run_skill(skill, params)  # run_skill 定义在本库 README
print(result.success, result.message)
```

**运行条件**：需要匹配的推理配置、模型、设备与环境；默认值不能证明推理服务可运行。

**结果判定**：初始化与每次执行均检查 Result.success；只有 is_finished() 为真才算完成。失败时保留 message 并定位上游输入或适配器。本片段为源码核对示例，仿真/真机验证待逐项记录。

## 感知目录的其他技能

感知目录有 5 个 skill.py，其中 read_qrcode/camera_capture/skill.py 与顶层 camera_capture/skill.py 同名；需要按实际导入路径核对，不直接算作 5 个独立公开能力。它们不统一遵循 refactored_sdk 的 hw 构造协议，不能套用上方调用片段。

| 能力 | 源码与构造入口 | 使用前核对 |
|---|---|---|
| 相机取帧 | skills/atomic/perception/camera_capture/skill.py，CameraCaptureSkill(camera) | ICamera 实例、帧话题和时间戳 |
| 二维码读取 | skills/atomic/perception/read_qrcode/skill.py，ReadQRCodeSkill(camera, config) | 目前 `execute()` 返回固定演示数据，**不做真实识别** |
| 托盘位姿 | skills/atomic/perception/pallet_pose/skill.py，PalletPoseSkill(window, smooth_mode) | 图像/深度输入和平滑窗口 |
| 托盘伺服 | skills/atomic/perception/pallet_servo/skill.py，PalletServoSkill(log_every_n) | 视觉偏差、周期、收敛判据 |

使用前请用离线样本或实际相机环境自行验证，并记录输入与预期输出。

### 相机取帧

`CameraCaptureSkill` 实现了 `initialize → execute → is_finished`。下例的 `camera` 必须是已经准备好、能返回相机帧的 `ICamera` 实例；`head` 是源码默认相机类型，不保证当前设备存在。

```python
from skills.atomic.perception.camera_capture.skill import CameraCaptureParams, CameraCaptureSkill

skill = CameraCaptureSkill(camera)
result = run_skill(skill, CameraCaptureParams(camera_type="head"))
print(result.success, result.message)
```

### 二维码演示占位

此实现的 `execute(params)` 直接返回固定的 `SMT_TRAY_001` 演示内容，没有实际取帧、解码和定位；因此不能用下例的成功返回证明识别链路可用。它也没有通用调用循环中的 `initialize` / `is_finished`。目前源码还从 `core.domain` 导入未导出的 `Pose` 和 `ErrorCode`，直接导入该模块会失败；下面只是**当前源码预期接口的示意**，待代码修复并验证后才能运行。

```python
from skills.atomic.perception.read_qrcode.skill import ReadQRCodeSkill

skill = ReadQRCodeSkill(camera=None)
result = skill.execute({})
print(result.success, result.message)  # 当前源码把固定演示字典放进 message
```

### 托盘位姿与托盘伺服

两者是纯计算技能，但必须使用**有效的输入对象**。`PalletPoseParams` 需要标定产物 `pallet_tag` 与本帧 `tag_poses`；`PalletServoParams` 需要托盘位姿、箱子观测、台面尺寸与相机几何参数。下列片段展示构造位置，输入来自标定文件/感知结果，而不是可直接复制的虚构位姿；字段单位和坐标系请先查相应源码与场景配置。

```python
from skills.atomic.perception.pallet_pose.skill import PalletPoseParams, PalletPoseSkill
from skills.atomic.perception.pallet_servo.skill import PalletServoParams, PalletServoSkill

pose_params = PalletPoseParams(tag_poses=tag_poses, pallet_tag=pallet_tag)
pose_result = run_skill(PalletPoseSkill(), pose_params)
if not pose_result.success:
    raise RuntimeError(pose_result.message)
pallet_pose = pose_result.data["pose"]

servo_params = PalletServoParams(
    pallet_pose=pallet_pose,
    box_obs=box_obs,
    pallet_size_mm=pallet_size_mm,
    K=intrinsics,
    D=distortion,
)
servo_result = run_skill(PalletServoSkill(), servo_params)
print(servo_result.success, servo_result.message)
```

这里的 `tag_poses`、`pallet_tag`、`box_obs`、`pallet_size_mm`、`intrinsics` 和 `distortion` 需要调用者按实际环境提供。`PalletPoseSkill` 成功时将位姿放在 `Result.data["pose"]`；本轮未验证两者端到端串联。
