# 标准技能卡模板

[返回标准技能库](README.md) · [收录与验收标准](收录与验收标准.md)

复制下列字段，为**经过验收的具体能力**建立独立 Markdown；当前模板不是已发布技能。

```text
# 技能名称

状态：候选 / 待验证 / 已发布 / 已弃用
维护者：
适用代码版本与机器人型号：
实现与调用入口：
关联原子技能、节点与案例：

## 做什么、不做什么
## 前置环境与服务检查
## 参数（类型、单位、默认、边界）
## 返回值、完成条件与失败判定
## 可复制调用示例与预期输出
## 验证记录（静态 / 干跑 / 仿真 / 真机分开）
## 已知限制与升级说明
```

验证记录应注明实际执行的命令、环境、结果和日期。对外展示前逐项对照[验收标准](收录与验收标准.md)；没有实测的栏位如实写“未验证”。
