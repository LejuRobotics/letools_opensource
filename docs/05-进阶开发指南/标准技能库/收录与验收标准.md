# 标准技能收录与验收标准

[返回标准技能库](README.md) · [技能卡模板](技能卡模板.md)

## 收录对象

候选可以由一个原子技能或一组技能/节点组成，但必须有清楚、稳定的对外调用契约。仅在案例中出现、能被 `import`，或通过 `--dry-run --tick-once`，都不足以认定为标准技能。

## 发布前逐项核对

1. **接口与版本**：记录入口、参数类型和单位、输入输出、返回值、超时与取消语义，标明适用的代码版本及机器人型号；与实现逐项对照。
2. **环境与依赖**：写明 ROS、SDK、TF、相机、夹爪等实际依赖；区分无需硬件、MuJoCo 和真机。仿真替代输入须明确不能验证的部分。
3. **最小复现**：给出可复制的准备与调用步骤、可观察的成功判据和失败排查；所有链接指向仓库内实际文件。示例参数不得把占位数据写成可直接用于真机的目标。
4. **验证证据**：记录测试命令和结果；涉及动作时记录在对应仿真或真机上的验证环境与结果。代码静态检查、干跑和真实动作验证分别登记，不互相替代。
5. **维护与变更**：指定维护者、适用范围、已知限制；参数或控制路径变化时同步更新技能卡与案例。

验收表中任一项缺失，状态保持“候选/待验证”，不得标为“已发布”。用[技能卡模板](技能卡模板.md)存证，并由维护者复核后在[库首页](README.md)登记。
