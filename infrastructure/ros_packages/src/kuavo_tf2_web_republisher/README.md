## 在 LeTools 中的位置

```text
kuavo_tf2_web_republisher
├── ROS 基础设施层
│   └── infrastructure/ros_packages/src/kuavo_tf2_web_republisher
│
├── TF 转发层
│   └── 选择性转发 /tf 和 /tf_static 中的坐标变换
│
└── Web 可视化层
    └── 为网页端或可视化工具提供需要的 TF 数据
```

> 这是来自 Robot Web Tools 生态的 ROS 包，LeTools 中主要把它作为基础设施依赖使用。
